# 🐍 python-modules
A collection of Python modules that I'm learning through hands-on practice. This repository contains notes, and automation scripts covering Python's standard library and commonly used third-party modules, with a focus on real-world applications in automation, scripting, and cybersecurity.

## 📚 Python Modules

- 📁 [OS Module](01-os/) — File, directory, and operating system operations.
- 🛤️ [Pathlib Module](02-pathlib) — Object-oriented file and path handling.
- ⚙️ [Subprocess Module](03-subprocess) — Run and manage external system commands.
- 🌐 [Requests Module](04-requests) — Send HTTP requests and interact with web APIs.
